# CampusFlow

校园资源预约与候补平台，首个业务场景是实验室共享工作站的固定时段预约。

## 当前进度

仓库处于初始化阶段，目前只包含项目说明、Git 忽略规则和换行规则，尚未创建可运行的 Spring Boot 应用。

## 初始技术计划

- Java 21、Spring Boot 3.5.16、Spring MVC。
- MySQL、Spring Data JPA、数据库事务与乐观锁。
- Maven Wrapper。
- 后续按功能接入 Redis / Lua、RabbitMQ、认证与候补机制。

## 实现顺序

1. 验证 JDK，创建空应用并运行最小接口。
2. 设计资源、时段、预约模型，接入数据库。
3. 完成预约与取消，验证数据库约束及并发控制。
4. 加入认证、Redis、Lua 与失败恢复。
5. 加入 RabbitMQ、消费幂等、重试和死信处理。
6. 实现候补与超时确认，记录故障实验和真实压测结果。

每个阶段验收后再进入下一阶段。性能数据和功能完成情况随实际验证结果更新。
